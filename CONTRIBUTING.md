# Contributing

This library is maintained for the needs of the app that uses it. Contributions are welcome, but there is no promised roadmap, support
window or response time.

Please open an issue before starting anything beyond a small fix, so the scope can be agreed first. A fix or a new server call should come
with a test (the tests answer requests with `StubURLProtocol`, so no ComfyUI server is needed) and a note in `CHANGELOG.md`. Name the
ComfyUI version whose behaviour a change relies on.
